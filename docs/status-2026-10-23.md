# FindMyWalk status — 23 October 2026

Source branch: `build/platform-20261023` in `lozknowles/FindMyWalk`. Development and testing took place on hpubuntu in an isolated worktree; the original checkout and unrelated work were left untouched. The user authorised a live release. This report tracks a bounded Nottinghamshire beta, not completion of the full master mission.

## Current beta candidate

- Responsive route editor, local Valhalla pedestrian routing, saved private drafts, unlisted link sharing with an immutable snapshot, GPX import/export, local OpenStreetMap place and mapped-stop discovery, and approximate browser AR Explorer with tap-to-route.
- The Nottinghamshire OSM import contains 18,691 mapped features and settlements from the 20 October 2026 extract (SHA-256 `e4a12f00c3fde61811d33dc10d3c39ed3fdb39bc70247650ab3e5274f4f210b3`). Local name search replaces the public Photon demo. OpenFreeMap provides displayed tiles with attribution.
- Anonymous browser editing defaults to private, public publishing is disabled, and sharing is explicitly unlisted. Owners can stop sharing or delete a walk, and all saved walks remain reachable. Shared pages and route APIs carry noindex guidance. The UI warns that clearing the editing cookie loses access. A report form and operator review table are present. Routing and writes have bounded bodies, process-wide admission, per-owner and global storage budgets (25/250,000 points per browser; 1,000/1,000,000 points in total), and an emergency write switch.
- A dedicated production Compose stack on hpubuntu has independent PostGIS and routing volumes and private credentials. The image runs as non-root without local secrets; database and router images are pinned by digest. CottageServer can reach the private upstream over Tailscale. The live domain still serves its holding page until the reviewed cutover.
- An encrypted database backup was copied to CottageServer with matching SHA-256. An isolated PostGIS restore of the remote copy recovered a published snapshot, 18,691 POIs, coverage and report data; a spatial query succeeded. The temporary route was removed from production and a fresh backup taken. A daily backup timer is installed. No external alert destination is configured.

## Verification

- 49 unit tests, TypeScript and optimized Next.js build pass on hpubuntu. Core desktop/mobile browser smoke passed for route create/save/share/GPX/private read checks, six saved-walk links, Stop sharing cross-browser revocation, owner deletion and nonowner edit denial, and AR browser smoke passed with a denied-camera fixture and simulated GPS fixture calling the real local router.
- The private production upstream returned a genuine 1,226 m walking route; create → private read denied → unlisted visitor read → public publish rejected → delete/revoke passed. Secure cookie attributes, foreign Origin rejection, oversized routing body rejection, outside-coverage response, local town search and report submission passed.
- Camera labels currently use horizontal compass bearing and an assumed 65° field of view, with fixed vertical lanes. Desktop/browser fixtures do not prove physical sensor alignment or real-world AR accuracy.

## Remaining master-mission gaps

Registered accounts, verification/recovery and profile tools; nationwide/international route and POI coverage; live Google Places presentation and credentials; current business opening data and transport timetables; route-corridor filters and community discovery/moderation; elevation/accessibility assessment; route-following/offline maps; and AR pitch/roll calibration, terrain occlusion, visual recognition, junction guidance and return-to-route remain unimplemented or unqualified. The beta covers Nottinghamshire only. Mapped paths do not establish public rights of way or current safety.

Live status and exact deployed image will be recorded after HTTPS cutover and external acceptance. Until then, the holding page is LIVE and the beta candidate is NOT LIVE.
